# Lilian Kariuki Portfolio

A responsive, editorial-style portfolio landing page for Lilian Kariuki, Front Office / Receptionist.

## Files
- `index.html` — page content and structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Before publishing
- Replace the illustrative Unsplash image in `index.html` with Lilian's own professional photo when available.
- Check the dates and role details for accuracy.
- The Google Fonts and Unsplash image require an internet connection.
